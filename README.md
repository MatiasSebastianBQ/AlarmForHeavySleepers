# HeavySleepers ⏰

**HeavySleepers** es una aplicación para iOS diseñada para personas que tienen dificultades para despertarse con las alarmas convencionales.

El proyecto nace con el objetivo de ofrecer una experiencia de despertador más eficaz, intuitiva y accesible, aprovechando las posibilidades del desarrollo nativo en el ecosistema de Apple.

## 📌 Descripción del proyecto

Despertarse a tiempo puede resultar complicado para las personas con sueño profundo o que suelen apagar las alarmas sin llegar a despertarse por completo.

HeavySleepers es un proyecto personal de desarrollo de software que busca explorar soluciones a este problema cotidiano mediante una aplicación móvil sencilla y funcional.

El desarrollo se centra en la creación de una interfaz intuitiva, una buena experiencia de usuario y el aprendizaje de tecnologías nativas para iOS.

## ✨ Funcionalidades

- **Gestión de alarmas:** experiencia orientada a la configuración y administración de alarmas.
- **Interfaz intuitiva:** diseño sencillo, claro y centrado en la facilidad de uso.
- **Desarrollo nativo:** aplicación creada para el ecosistema de Apple.
- **Mejora continua:** proyecto en evolución con posibilidad de incorporar nuevas funcionalidades.

*Nota: las funcionalidades descritas representan los objetivos del proyecto y deberán actualizarse conforme se implementen en la aplicación.*

## ⚙️ Instalación y ejecución

### Requisitos previos

- Un Mac con una versión compatible de macOS.
- Xcode instalado.
- Un simulador de iOS o un dispositivo Apple compatible para ejecutar la aplicación.

### Pasos para ejecutar el proyecto

1. Clonar el repositorio:

   ```bash
   git clone https://github.com/MatiasSebastianBQ/AlarmForHeavySleepers.git
   ```

2. Acceder a la carpeta del proyecto.

3. Abrir el archivo `HeavySleepers.xcodeproj` con Xcode.

4. Seleccionar un simulador de iOS o un dispositivo compatible.

5. Ejecutar la aplicación mediante **Product → Run** o pulsando `⌘R`.
